# QR code menù Pescheria da Dany

QR code che apre il menù digitale della Pescheria da Dany (Selargius).

- `qr-menu.png`: il QR da stampare o inserire nelle grafiche.
- `index.html`: pagina che mostra il QR, con il pulsante per scaricarlo.

## Inserirlo in un'altra pagina

```html
<img src="https://raw.githubusercontent.com/Piguz-afk/qr_code_pescheria/main/qr-menu.png"
     alt="QR code menù Pescheria da Dany" width="300">
```

Il link `raw.githubusercontent.com` funziona solo se il repository è pubblico.
